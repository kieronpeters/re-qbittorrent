# Evidence log

Findings recorded here must be reproducible from the target digest and the
tool/version used. Tag every statement:

- **Verified** - returned directly by a tool.
- **Deduction** - deterministic inference from verified facts.
- **Hypothesis** - plausible interpretation; name the alternatives.
- **Unknown** - not established by available evidence.

Do not paste third-party binaries, symbol files, or long verbatim decompiler
output into this directory. Summarise, cite addresses/digests, and keep raw
artifacts outside the repository.
